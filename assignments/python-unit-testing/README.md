# 📘 Assignment: Writing and Running Unit Tests in Python

## 🎯 Objective

In this assignment, you will learn how to write and run unit tests using pytest. You will practice creating test cases, reading assertion failures, and fixing code based on test results.

## 📝 Tasks

### 🛠️ Write Unit Tests with Pytest

#### Description
Use pytest to test the functions in starter-code.py. Focus on normal behavior and edge cases so your tests clearly show whether each function works correctly.

#### Requirements
Completed program should:

- Create test functions in test-starter.py for each function in starter-code.py.
- Use clear test names that describe expected behavior.
- Include at least 6 total tests across all functions.
- Include at least 2 edge-case tests (for example, empty input or zero values).
- Run tests with pytest and confirm test output shows passed/failed results.


### 🛠️ Debug and Fix Failing Code

#### Description
Run your tests, identify failing cases, and fix the implementation in starter-code.py until all tests pass.

#### Requirements
Completed program should:

- Use failing test messages to identify what is wrong in the functions.
- Update starter-code.py to satisfy all expected behaviors.
- Keep function names and parameters unchanged.
- Re-run pytest after each fix to verify progress.
- Finish with all tests passing.
